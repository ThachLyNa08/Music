# Song Semantic Profile Pipeline

This pipeline generates semantic profiles for songs (themes, moods, situations, emotion intensity) using either a rule-based matching system or an LLM (Gemini). It also generates TF-IDF text embeddings of the semantic descriptions.

## Prerequisites
The following environment variables are required in `apps/backend/.env`:
```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=musicflow
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```

## Running the Pipeline

### Rule-based Generation (Dry Run)
To test the rule-based system without writing to the database (outputs a CSV preview):
```bash
python apps/ai-service/scripts/recommendation/generate_song_semantic_profiles.py --limit 20 --dry-run
```

### Gemini-based Generation (Dry Run)
To test with the Gemini LLM (requires `GEMINI_API_KEY` and `google-genai` package):
```bash
python apps/ai-service/scripts/recommendation/generate_song_semantic_profiles.py --limit 5 --dry-run --use-gemini
```

### Evaluation
After generating the CSV preview, run the evaluation script to check distributions and data quality:
```bash
python apps/ai-service/scripts/recommendation/evaluate_song_semantic_profiles.py --input datasets/processed/semantic/previews/song_semantic_profiles_python_preview.csv
```

## Output Files
- `datasets/processed/semantic/previews/song_semantic_profiles_python_preview.csv`: The generated semantic profiles.
- `datasets/processed/semantic/embeddings/song_semantic_embeddings.npy`: Numpy array containing TF-IDF text embeddings.
- `datasets/processed/semantic/embeddings/song_semantic_embeddings_meta.csv`: Metadata mapping array indices to song IDs.
- `datasets/processed/semantic/reports/song_semantic_profiles_python_summary.json`: JSON summary output of evaluation.
- `docs/recommendation/song_semantic_profile_report.md`: The Markdown evaluation report generated by the evaluation script.

## Important Note
This pipeline is designed for offline evaluation and thesis reporting. It does NOT automatically write to the database or modify live application state.
